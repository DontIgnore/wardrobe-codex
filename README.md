# Гардероб — локальный прототип

Личный локальный гардероб: фото образа → распознавание вещей и координат → кропы → параллельная генерация каталожных снимков через `codex exec`.

Для запуска нужны Python 3.12+, Git, Codex CLI и вход в Codex через ChatGPT с доступом к встроенной генерации изображений. Если CLI ещё не установлен, его можно установить через npm: `npm install -g @openai/codex` (нужен Node.js/npm). На исходном компьютере проверена версия Codex CLI 0.147.0. На другом устройстве доступность встроенного imagegen и модели может отличаться.

Первичная настройка на Windows (PowerShell):

```powershell
git clone https://github.com/DontIgnore/wardrobe-codex.git
cd wardrobe-codex
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
codex login
.venv\Scripts\python.exe server.py
```

На macOS/Linux:

```sh
git clone https://github.com/DontIgnore/wardrobe-codex.git
cd wardrobe-codex
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
codex login
.venv/bin/python server.py
```

Репозиторий приватный: для клонирования нужен доступ к аккаунту DontIgnore (например, после `gh auth login` и `gh auth setup-git`). В браузере откройте http://127.0.0.1:8765. При повторном запуске на Windows можно открыть `start.cmd`: он использует `.venv`, если окружение создано. На macOS/Linux повторите `.venv/bin/python server.py`. Локальный адрес работает на том устройстве, где запущен сервер.

На новом устройстве коллекция изначально пустая. Фотографии, результаты, кропы, журналы и авторизация не входят в Git. Сервер сам создаёт папку `data/`. Инструкции генерации включены в `skills/imagegen/SKILL.md` — копировать системный навык с первого компьютера не требуется.

Загрузите JPG/PNG до 15 МБ и 40 мегапикселей. Приложение автоматически распознаёт вещи и их координаты, обрезает исходник вокруг каждой вещи и параллельно генерирует отдельные снимки. Каждый готовый снимок можно открыть или скачать. Ссылка «Крупный план» открывает реальный кроп, переданный генератору. Неудачную генерацию можно повторить. Кнопка «Разобрать заново с крупными планами» создаёт новое задание, сохраняя предыдущие результаты. При перезапуске незавершённые задачи помечаются прерванными, повтор выполняется только по кнопке.

Распознавание включает украшения и бижутерию: кольца, браслеты, часы, серьги, цепочки/кулоны, броши, анклеты и украшения для волос, если они различимы на фото. Каждое различимое кольцо получает отдельную карточку и кроп. Неразделимая стопка украшений может быть одним предметом; совпадающая видимая пара серёг — одной карточкой. Скрытые украшения не предполагаются. Категории появляются в фильтрах автоматически. За один разбор допускается до 32 предметов; одновременно генерируются максимум 8, остальные ожидают свободного места.

Мелкие украшения могут занимать всего несколько пикселей: кроп фокусирует внимание, но не восстанавливает точную огранку, надписи или невидимую застёжку. Генерация получает инструкцию сохранять видимую форму и не придумывать драгоценные камни, гравировки и бренды. Часы и украшения показываются отдельно, без кожи, пальцев и подставок. Старые разборы не дополняются автоматически: для нового поиска украшений нажмите «Разобрать заново с крупными планами» или загрузите фото заново.

Первый `codex exec` получает исходное изображение и возвращает JSON: `name`, `category`, `description`, `details`, `bbox`. Координаты `bbox=[left,top,right,bottom]` нормализованы от 0 до 1, начало в левом верхнем углу. Pillow обрезает фото в исходном разрешении, добавляя 4% с каждой стороны (минимум 8 пикселей) и ограничивая область границами фотографии. EXIF-поворот нормализуется при загрузке. Для пары обуви или сумки со шлейкой используется одна общая рамка.

Каждая генерация — отдельный `codex exec` со встроенным imagegen; ему передаётся только соответствующий кроп и описание деталей. Генератор дополнительно рассматривает мелкую фурнитуру на кропе. Обрезка прямоугольная, без модели сегментации: перекрывающие руки/одежда внутри рамки остаются. Кроп не восстанавливает отсутствующую информацию и не гарантирует точное копирование деталей.

API-ключ не нужен; расходуются лимиты Codex. Фотографии отправляются Codex для обработки, файлы хранятся в `data/<job-id>`. В каждой папке также есть промпты, события и диагностические журналы. Сервер раздаёт исходники, кропы и готовые изображения, не журналы. Старые задания сохранены; повтор отдельной старой карточки без координат использует целый исходник, новый разбор через кнопку создаёт кропы.

По умолчанию используется `gpt-5.6-sol`: эта модель успешно прошла локальный тест. Модель `gpt-6.1-sol`, настроенная в пользовательском CLI, в тесте была отклонена сервером при входе через ChatGPT. Общий конфиг не изменялся.

Если модель недоступна на другом аккаунте, задайте доступную модель до запуска сервера: `$env:WARDROBE_MODEL="имя-модели"` в PowerShell или `export WARDROBE_MODEL="имя-модели"` в macOS/Linux. Проверка входа: `codex login status`. При занятом порте задайте `WARDROBE_PORT`, затем откройте адрес с этим портом. Если CLI установлен нестандартно, задайте `WARDROBE_CODEX` как полный путь к исполняемому файлу. API-ключ и файлы авторизации переносить не нужно.

Переменные окружения: `WARDROBE_MODEL`, `WARDROBE_CODEX` (путь к исполняемому Codex), `WARDROBE_PORT` (по умолчанию 8765), `WARDROBE_PARALLEL` (по умолчанию 8, диапазон 1–8). Все пять вещей тестового образа запускаются одновременно, результаты сохраняются по мере готовности. Разные образы проходят очередь последовательно. Генерация ограничена 20 минутами на одну вещь. Ошибка одной вещи не останавливает остальные; лимиты аккаунта могут ограничивать реальную параллельность.

Это личный локальный прототип: сервер слушает только 127.0.0.1. Не публикуйте его в интернете без добавления авторизации и ограничений ресурсов. Генерация может реконструировать скрытые детали и менять отдельные особенности вещей. Встроенная генерация и доступность моделей зависят от установленной версии Codex и аккаунта.

Чтобы подключить API позже, замените `CodexProcessor` (методы `analyze` и `generate`), сохранив формат заданий и изображений. Интерфейс и сохранённый гардероб от способа генерации не зависят.

Приложение проверено на предоставленной фотографии: распознаны топ, брюки, мокасины, сумка и очки. Результаты сохранены только в локальной коллекции исходного компьютера и не включены в репозиторий.

Проверки логики: `python -m unittest test_server -v`. Они проверяют отклонение неверных координат, границы и пиксели кропа, фактическое параллельное выполнение через барьер двух потоков, продолжение очереди после ошибки и повтор отдельной вещи без изменения уже готовых карточек. Для диагностики живого запуска смотрите `data/<job-id>/*-events.jsonl` и `*-stderr.log`.
