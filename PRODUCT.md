# Гардероб

## Platform
web

## Purpose
Личный локальный прототип: загрузить фото человека в одежде, распознать вещи и аксессуары, автоматически сгенерировать отдельные каталожные изображения и показать коллекцию.

## Confirmed workflow
Пользователь выбрал автоматическую генерацию всех найденных вещей, без промежуточного выбора. Для первой версии используется Codex exec со встроенным imagegen; позже предполагается API. На исходной фотографии показаны топ, брюки, обувь, сумка и очки.

## Implementation choices
Локальный Python-сервер с Pillow для обрезки изображений, HTML/CSS/JavaScript без сборки. Это выбор реализации для малого прототипа, а не требование пользователя. Русский интерфейс, локальное хранение. Образы идут по очереди, вещи одного образа генерируются параллельно (до 8 одновременно). Авторизация и публичный хостинг в этот прототип не входят.

## Updated workflow
По просьбе пользователя распознавание возвращает координаты каждого предмета. Сервер создаёт отдельные прямоугольные кропы и передаёт их в генерацию вместо целого кадра. Ссылка «Крупный план» позволяет проверить вход генератора. Описание фиксирует мелкие детали и неопределённость. Это обрезка, не сегментация и не восстановление скрытых деталей.

Украшения и часы включены в распознавание наравне с одеждой: кольца, браслеты, серьги, цепочки/кулоны, броши, анклеты и украшения для волос. Каждое различимое украшение получает отдельные координаты и карточку; неразделимые стопки отмечаются как группа. Лимит разбора — 32 предмета, параллельная генерация — до 8. Старые результаты сохраняются, новый поиск украшений требует повторного разбора фотографии.

## Success
Фотография загружается один раз; карточки пополняются автоматически. Ошибка одной вещи не прерывает остальные. Картинки доступны после перезапуска.
