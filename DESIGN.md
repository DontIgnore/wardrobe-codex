# Визуальное направление

Практический инструмент с коллекцией фотографий в центре внимания. Спокойная светлая поверхность для сравнения светлых вещей, тёмный оливковый акцент, читаемые подписи. Исходный снимок остаётся у каждой группы карточек.

Режим: Operate. Слева загрузка, справа коллекция; на узком экране загрузка располагается сверху. Фильтры по категориям, явные состояния очереди, распознавания, генерации, готовности и ошибки. Внешние шрифты и внешние изображения не используются. Обложки карточек — реальные результаты генерации.
